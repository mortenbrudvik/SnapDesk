# SnapDesk v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a macOS menu-bar app that captures the current desk into a double-clickable `.snapdesk` JSON file and restores those apps to the saved displays and frames.

**Architecture:** Loadstone-shaped Swift 6 agent (`LSUIElement`). Capture reads `NSRunningApplication` + Accessibility + `CGWindowList`; the `.snapdesk` file is the source of truth; launch uses `NSWorkspace` then AX size→position→size. Editor and launch HUD are on-demand windows. Recents are bookmarks, not a second copy of the workspace.

**Tech Stack:** Swift 6, AppKit + SwiftUI editor, Accessibility (`ApplicationServices`), XcodeGen, KeyboardShortcuts 2.x, XCTest with `TEST_HOST`, macOS 14+, arm64, not sandboxed.

**Spec:** `docs/superpowers/specs/2026-09-09-snapdesk-design.md`

`FramePlacement.swift`:

```swift
import CoreGraphics

enum FramePlacement {
    static func relative(cocoa: CGRect, visibleFrame: CGRect) -> CGRect {
        CGRect(
            x: cocoa.minX - visibleFrame.minX,
            y: cocoa.minY - visibleFrame.minY,
            width: cocoa.width,
            height: cocoa.height
        )
    }

    static func cocoa(relative: CGRect, visibleFrame: CGRect) -> CGRect {
        CGRect(
            x: relative.minX + visibleFrame.minX,
            y: relative.minY + visibleFrame.minY,
            width: relative.width,
            height: relative.height
        )
    }

    static func restore(relative: CGRect, savedVisible: CGRect, liveVisible: CGRect) -> CGRect {
        let sizeMatches =
            abs(savedVisible.width - liveVisible.width) <= 1
            && abs(savedVisible.height - liveVisible.height) <= 1
        if sizeMatches {
            return cocoa(relative: relative, visibleFrame: liveVisible)
        }
        let sx = liveVisible.width / max(savedVisible.width, 1)
        let sy = liveVisible.height / max(savedVisible.height, 1)
        let scaled = CGRect(
            x: relative.minX * sx,
            y: relative.minY * sy,
            width: relative.width * sx,
            height: relative.height * sy
        )
        return cocoa(relative: scaled, visibleFrame: liveVisible)
    }

    static func clamp(_ frame: CGRect, to visible: CGRect, titleBar: CGFloat = 80) -> CGRect {
        var result = frame
        if result.width > visible.width || result.height > visible.height {
            return visible
        }
        if result.maxX < visible.minX { result.origin.x = visible.minX }
        if result.minX > visible.maxX { result.origin.x = visible.maxX - result.width }
        let minTitleTop = visible.minY + titleBar
        if result.maxY < minTitleTop { result.origin.y = minTitleTop - result.height }
        if result.minY > visible.maxY { result.origin.y = visible.maxY - result.height }
        if result.maxX > visible.maxX { result.origin.x = visible.maxX - result.width }
        if result.minX < visible.minX { result.origin.x = visible.minX }
        if result.maxY > visible.maxY { result.origin.y = visible.maxY - result.height }
        if result.minY < visible.minY { result.origin.y = visible.minY }
        return result
    }
}
```

- [ ] **Step 3: Implement tokenizer**

```swift
enum ArgumentTokenizer {
    static func tokenize(_ raw: String) -> [String] {
        var tokens: [String] = []
        var current = ""
        var quote: Character?
        for ch in raw {
            if let q = quote {
                if ch == q { quote = nil } else { current.append(ch) }
                continue
            }
            if ch == "\"" || ch == "'" {
                quote = ch
                continue
            }
            if ch.isWhitespace {
                if !current.isEmpty {
                    tokens.append(current)
                    current = ""
                }
                continue
            }
            current.append(ch)
        }
        if !current.isEmpty { tokens.append(current) }
        return tokens
    }
}
```

static func decode(_ data: Data) throws -> WorkspaceDocument {

        throw error

}

    let encoder = JSONEncoder()
    encoder.outputFormatting = [.prettyPrinted, .sortedKeys]

### Task 10: LaunchService

**Files:**
- Create: `SnapDesk/Core/LaunchService.swift`
- Test: `SnapDeskTests/LaunchServiceTests.swift`

**Interfaces:**
- Consumes: `WorkspaceDocument`, `LaunchPlanner`, `WindowMatcher`, `DisplayMap`, `FramePlacement`, `ArgumentTokenizer`, `MatchableWindow`
- Produces:
  - `enum SlotStatus: Equatable` — `pending`, `launching`, `placed`, `failed(String)`
  - `struct SlotProgress: Equatable` — `index: Int`, `name: String`, `status: SlotStatus`
  - `struct LaunchConfiguration: Equatable` — `arguments: [String]`, `createsNewApplicationInstance: Bool`, `activates: Bool`
  - `protocol ApplicationLaunching` — `func urlForApplication(bundleIdentifier: String) -> URL?`; `func applicationExists(at path: String) -> Bool`; `func openApplication(at url: URL, configuration: LaunchConfiguration) async throws`
  - `protocol RunningApplicationQuerying` — `func runningBundleIDs() -> Set<String>`; `func unhide(bundleIdentifier: String)`; `func activate(bundleIdentifier: String)`
  - `protocol WindowCatalog` — `func standardWindows(bundleIdentifier: String) -> [MatchableWindow]`; `func waitForWindow(bundleIdentifier: String, excluding: Set<String>, timeout: Duration) async -> MatchableWindow?`
  - `protocol WindowPlacing` — `func place(_ window: MatchableWindow, cocoaFrame: CGRect, minimized: Bool, zoomed: Bool) -> Bool` (false = AX refused)
  - `protocol Clock` — `func sleep(_ duration: Duration) async` (tests use no-op / immediate)
  - `@MainActor final class LaunchService` — `init(launcher:apps:windows:placer:displays:clock:launchTimeout:windowTimeout:)` with production defaults `launchTimeout = .seconds(10)`, `windowTimeout = .seconds(8)`
  - `func launch(_ document: WorkspaceDocument, onProgress: @MainActor ([SlotProgress]) -> Void) async -> [SlotProgress]`
  - `func cancel()` — remaining slots that are still `pending` become `failed("Cancelled")`; in-flight launch is not killed

Algorithm:

1. If `windows.isEmpty`, call `onProgress([])` and return `[]`.
2. Build `SlotProgress` all `.pending`.
3. `let plans = LaunchPlanner.plan(document:runningBundleIDs: apps.runningBundleIDs())`.
4. For each index in `LaunchPlanner.placeOrder(windowCount:)`:
   - Stop if cancelled.
   - Set status `.launching`; `onProgress`.
   - Resolve URL: `urlForApplication(bundleIdentifier)` else `applicationExists(at: bundlePath)` → `URL(fileURLWithPath:)`. Else `.failed("App not found")`.
   - If action is `.launch`, `openApplication`. On throw → `.failed("Launch failed")`.
   - If action is `.reuse`, `unhide`.
   - `waitForWindow` excluding claimed ids. Nil → `.failed("No window")`.
   - `WindowMatcher.match` if wait returned a pool instead of one window: production `waitForWindow` should return one unclaimed window; if multiple exist, matcher runs on `standardWindows` with the claimed set.
   - Insert claimed id.
   - Map display via `DisplayMap.resolve` (live from `displays()`, main = first or a dedicated `main`).
   - `FramePlacement.restore` then `clamp`.
   - `place(...)` false → `.failed("Could not position")` (still claimed).
   - Else `.placed`.
5. After the loop, `activate` the bundle ID of `windows[0]` if that slot is `.placed`, else the first `.placed` in list order.

Production adapters use `NSWorkspace` + `AXWindow` + `DisplayMap`. `waitForWindow` polls every 0.1 s until timeout.
